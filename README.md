# E-Commerce City & Product Performance Analytics

## Project Overview
This project analyzes e-commerce data to understand sales performance, customer satisfaction, and delivery efficiency across cities and product categories.

## Dataset
Brazilian E-Commerce Public Dataset by Olist.

## Tools Used
- MySQL
- Power BI
- SQL for data analysis and business insights

## Project Objectives
- Analyze revenue by city and product category.
- Identify delivery delays and logistics issues.
- Evaluate customer review scores.
- Build an interactive Power BI dashboard.

## Project Status
Currently in progress.
